# Система оценки успеваемости студентов ПолесГУ

Веб-приложение для мониторинга и анализа успеваемости студентов инженерного факультета Полесского государственного университета.

## 📋 Описание

Система предназначена для:
- Ведения электронного журнала оценок студентов
- Анализа успеваемости по группам, дисциплинам и факультету в целом
- Формирования рейтингов студентов и учебных групп
- Генерации отчетов и статистики
- Управления данными о студентах, преподавателях и дисциплинах

## 🚀 Требования

- **Web-сервер**: Apache 2.4+ (или Nginx)
- **PHP**: 8.0+
- **База данных**: MySQL 5.7+ или MariaDB 10.3+
- **Расширения PHP**: PDO, pdo_mysql

## 📦 Установка

### 1. Размещение файлов

Скопируйте папку `polessgu_rating` в корневую директорию вашего веб-сервера:

**Для XAMPP/OpenServer:**
```
C:/xampp/htdocs/polessgu_rating/
```

**Для Linux (Apache):**
```
/var/www/html/polessgu_rating/
```

### 2. Создание базы данных

1. Откройте phpMyAdmin (http://localhost/phpmyadmin)
2. Создайте новую базу данных с именем `polessgu_rating`
3. Импортируйте SQL-файл:
   - Перейдите во вкладку "Импорт"
   - Выберите файл `/polessgu_rating/config/database.sql`
   - Нажмите "Выполнить"

**Или через командную строку:**
```bash
mysql -u root -p < /path/to/polessgu_rating/config/database.sql
```

### 3. Настройка подключения к БД

Откройте файл `/polessgu_rating/config/db_config.php` и при необходимости измените параметры подключения:

```php
define('DB_HOST', 'localhost');
define('DB_USER', 'root');
define('DB_PASS', '');  // Ваш пароль от MySQL
define('DB_NAME', 'polessgu_rating');
```

### 4. Проверка прав доступа

Убедитесь, что у веб-сервера есть права на чтение файлов:

**Linux:**
```bash
chmod -R 755 /var/www/html/polessgu_rating
chown -R www-data:www-data /var/www/html/polessgu_rating
```

## 🔧 Настройка виртуального хоста (опционально)

### Для Apache:

Создайте файл `/etc/apache2/sites-available/polessgu-rating.conf`:

```apache
<VirtualHost *:80>
    ServerName polessgu-rating.local
    DocumentRoot /var/www/html/polessgu_rating
    
    <Directory /var/www/html/polessgu_rating>
        Options Indexes FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>
    
    ErrorLog ${APACHE_LOG_DIR}/polessgu-rating_error.log
    CustomLog ${APACHE_LOG_DIR}/polessgu-rating_access.log combined
</VirtualHost>
```

Активируйте хост:
```bash
sudo a2ensite polessgu-rating.conf
sudo systemctl restart apache2
```

Добавьте в `/etc/hosts`:
```
127.0.0.1 polessgu-rating.local
```

## 🐛 Решение проблем

### Ошибка подключения к базе данных
- Проверьте правильность учетных данных в `db_config.php`
- Убедитесь, что служба MySQL запущена
- Проверьте имя базы данных

### Страница отображается как список файлов
- Убедитесь, что модуль mod_php включен в Apache
- Проверьте, что файлы имеют расширение `.php`

### Не работает вход в систему
- Проверьте, что база данных импортирована корректно
- Убедитесь, что таблица `users` содержит записи
- Проверьте логи ошибок PHP
