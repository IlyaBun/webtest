# Система оценки успеваемости студентов инженерного факультета ПолесГУ

## Дипломный проект

Веб-приложение для оценки количественных и качественных показателей успеваемости студентов.

---

## 📋 Описание проекта

Данная система предназначена для автоматизации процесса учета и анализа успеваемости студентов инженерного факультета Полесского государственного университета (ПолесГУ).

### Основные возможности:

1. **Главная панель (Dashboard)**
   - Общая статистика факультета
   - Средний балл
   - Количество отличников
   - Студенты с низкой успеваемостью
   - График распределения оценок
   - Последние добавленные оценки

2. **Управление студентами**
   - Просмотр списка всех студентов
   - Поиск по ФИО
   - Фильтрация по группе и статусу
   - Добавление/редактирование/удаление
   - Расчет среднего балла

3. **Дисциплины**
   - Список учебных предметов
   - Привязка к кафедрам и преподавателям
   - Управление учебными планами

4. **Оценки**
   - Ввод оценок студентов
   - Редактирование и удаление
   - История изменений
   - Поддержка 10-балльной системы

5. **Аналитика и отчеты**
   - Рейтинг студентов
   - Рейтинг групп
   - Анализ по дисциплинам
   - Динамика успеваемости
   - Качественные показатели

6. **Пользователи**
   - Система авторизации
   - Роли: Администратор, Преподаватель
   - Управление доступом

## ⚙️ Установка

### Требования:
- XAMPP / OpenServer / другой веб-сервер с PHP и MySQL
- PHP 7.4 или выше
- MySQL 5.7 или выше

### Шаг 1: Размещение файлов
Скопируйте папку `polessgu_rating` в директорию веб-сервера:
- Для XAMPP: `C:\xampp\htdocs\polessgu_rating`
- Для OpenServer: `OpenServer\domains\polessgu_rating`

### Шаг 2: Создание базы данных
1. Откройте phpMyAdmin (обычно http://localhost/phpmyadmin)
2. Создайте новую базу данных с именем `polessgu_rating`
3. Импортируйте файл `config/database.sql`
4. База данных автоматически заполнится тестовыми данными

### Шаг 3: Настройка подключения
Откройте файл `config/db_config.php` и при необходимости измените параметры:
```php
define('DB_HOST', 'localhost');
define('DB_USER', 'root');
define('DB_PASS', '');
define('DB_NAME', 'polessgu_rating');
```

### Шаг 4: Запуск
Откройте в браузере: `http://localhost/polessgu_rating`
